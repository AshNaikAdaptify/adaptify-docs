# Bring a product into the Vault

Watch this one-minute demo to see how a product goes into the **Product Vault** (the Vault). Then follow the four steps below. You can do them in one sitting.

## The four steps

1. [Create a product](create-product.md). Give it a name, its lines of business and its states.
2. [Upload documents for a state](import-documents.md). Add the forms, manuals and supporting materials for each state.
3. [Add metadata and process documents](process-documents/index.md). Add form numbers and editions, then let the Vault read your files and pull out the rules.
4. [Review and publish](review-and-publish.md). Publish each state so your team can start updating it.

## Before you start

- Your **Group** and **Underwriting company** are already set up. Your organization admin does this once. See [Before you start](before-you-start.md).
- Have your files ready for each state:

| Group | File types |
|---|---|
| Forms | Word (DOC, DOCX) or PDF |
| Manuals | Word, PDF or Excel |
| Supporting materials | PDF |

!!! tip "Use a file name of its own for each form"
    Give each form a file name that no other product in your Vault uses. Otherwise publishing the state can fail with "Failed to publish Product state". This is a known issue.
