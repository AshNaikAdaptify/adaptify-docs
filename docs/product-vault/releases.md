# Understand releases

A release is a version of a product's files for one state. Each state has its own releases, and the **Current release** is the one in use.

## When releases are created

- **First publish:** when you [publish a state](review-and-publish.md), it gets its **Baseline** release.
- **After an update:** when an approved filing is archived with **Create new release**, the state gets a new release, for example **Release 1**. The new release becomes the **Current release**. Each state gets its own new release when its filing is archived.

## See a state's releases

1. In **Product Vault**, open the product.
2. Under **Jurisdiction**, choose the state.
3. Under **Release**, choose a release. Earlier releases, such as **Baseline**, stay in the list.

The header shows the release's **New business** and **Renewal** dates. The **Current release** chip marks the release in use.

## See what changed

On the **Forms** tab, a form that changed in the release you're viewing shows an **Update** chip.
