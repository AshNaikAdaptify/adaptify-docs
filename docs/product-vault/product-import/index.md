# Product import

**Audience:** External

Bringing a product into the **Product Vault** (the Vault) takes four simple steps. You can do it in one sitting.

1. [Create the product](create-product.md).
2. [Upload files for each state](upload-files.md).
3. [Process and extract rules](process-and-extract-rules.md).
4. Review and publish your first release. `TODO verify`

## Before you start

Have your files ready for each state, in three groups:

| Group | File types |
|---|---|
| Forms | Word or PDF |
| Manuals | Word or Excel |
| Supporting documents | PDF |

!!! tip "One-time setup"
    Your **Group** and **Underwriting Company** should already exist in **System Administration** → **Lists**. See [Before you start](../before-you-start.md).
