# Add metadata and process documents

Processing turns a state's uploaded files into Vault assets, and pulls the rules out of your manuals. It needs a little information about each file first.

## Before you start

The state's files are uploaded. See [Upload documents for a state](../import-documents.md).

## The three steps

Do them in this order for each state:

1. [Add form numbers and editions](form-metadata.md). Each form needs its form number and edition.
2. [Add manual editions and set up rules](manual-editions-and-rules.md). Each manual needs an edition, and Word and PDF manuals need their rule setup.
3. [Process documents and check the rules](run-processing.md). Process the state, then check the rules that came through.

!!! tip "Add metadata first"
    Add every file's metadata before you process the state or use a file in another state.
