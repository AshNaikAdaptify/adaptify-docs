# Process documents and check the rules

Processing reads the state's files and pulls the rules out of your manuals. Afterwards, check the rules before you publish.

## Before you start

- Every form has its form number and edition. See [Add form numbers and editions](form-metadata.md).
- Every Word or PDF manual has its edition and rule setup. See [Add manual editions and set up rules](manual-editions-and-rules.md).

## Process the state

1. Open the product and choose the state under **Jurisdiction**.
2. Select **Process documents** once.
3. If you're told a manual isn't configured yet, cancel and set it up first. A manual processed without its rule setup may give you no rules.
4. Wait for processing to finish. Uploads and edits pause while it runs. Refresh the page to see the status move from **Processing** to **Processed**.

## Check the rules

1. Open the **Rules** tab and expand the tree, for example `1 MANUAL FORMAT` → `1.1 Multistate Rules Manual`.
2. Check that each manual's headings came through with their numbers and titles in order.
3. If rules are missing, check that manual's edition and rule setup on the **Manual** tab.

!!! note "Check the rules, not just the count"
    The **Rules** count can change after you edit metadata, and it doesn't always match the rule tree. Some titles can also come through wrong, for example a page number from a manual's index. These are known issues. Look at the rules themselves before you publish.
