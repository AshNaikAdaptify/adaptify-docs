# Get Started

Adaptify Insurance product Lifecycle Management is the operating system for P&C carriers

Centralize forms, rules, rates, workflows and governance in one easy to use platform

Use the left navigation to move between the areas below at any time.

## Dashboard

The Dashboard is the first page you see. It gives you a quick view of your projects, pending tasks and products.

## Project Workbench

Project Workbench is a collaborative environment for building new products and updating existing products.

- Your projects are listed in the **Project portfolio**. Use **Type** to filter them.
- Choose **New project** to start one for forms, rates or rules. Choose more than one type to create a combined project with a child project for each type. `TODO verify` where the **New project** button sits.

See [Workbench overview](../workbench/index.md).

## Filing Manager

Filing Manager lets you manage Filings and objection handling all the way to approvals.

- **Filings** shows each filing as a card with its state and status.
- Use **Search filings**, **Filters**, **Sort** and **Group** to find a filing, then open it.

See [Filing Manager overview](../filing-manager/index.md).
