# Build a new product in Workbench

A **New product** project takes a brand-new insurance product from idea to build in the Project Workbench (the Workbench). Your team works on it together, phase by phase, like any other project.

Already have the product's documents and just want it in the Product Vault? Use [Create a product](../../product-vault/create-product.md) instead.
