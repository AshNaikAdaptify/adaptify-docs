# Add the product's documents

After you [start a new product project](start.md), add the product's forms to it. A **Forms** project has a **Forms** tab only, with no **Rates** or **Rules** tabs.

## Add a form

1. Open the project in **Workbench**. On the **Forms** tab, select **Create form**. The **New document** dialog opens.
2. Under **Document type**, keep **New document**.
3. Enter a **Form Number**. When it says "Available. Use this number to lock it before continuing.", select **Use this number**. You see "Form number locked for this form."
4. Enter the **Edition** and the **Form Name**.
5. Select **Add Form**. The form is listed with the change type **Addition**.

Repeat for each form.
