# Update rates

Use a rate project to give one or more rate files a new edition. If your project is combined, first open its rates child project from the **Projects** tab.

## Steps

1. Open the project. Its **Rates** tab lists the rates in the project.
2. Start a rate change. The **Add rate changes** dialog opens.
3. Under **Change type**, choose **Update rate**, then choose **Next**.
4. Select the rates to update, then choose **Next**.
5. Enter the **Updated edition** when the dialog asks for it, for example 01 27.
6. Check the **Confirm** step, then confirm the change.

The rates appear on the **Rates** tab with their new edition. A rate project moves from **Select** straight to **End**: when the work is done, use **Submit** to move it to **End**.
