# Complete as Admitted (create filings)

Use **Admitted** for states that need a filing. Adaptify creates one filing for each state in **Filing Manager**.

## Steps

1. Go to **Workbench** and open the project. Every child project should be at **End**.
2. Select **Complete project**.
3. Choose the **Admitted** tab. The filing owners load for your organization.
4. For each state, choose the **Approval Type** (**Prior approval**, **File and use** or **Use and file**) and the **Owner**. The dialog tells you how many filing projects it will create.
5. Review the summary, then confirm.
6. Open **Filing Manager**. Each state has its own filing, named after your project and the state, for example "Filing - Personal Auto fall update (Form, Rate) (AL)".

!!! tip
    Pick any dates from the calendar. Don't press Escape inside a date field: it closes the whole dialog, and you start again.

## What happens next

Each state's filing moves on its own: build the package, file with the state, track objections, record the approval and archive to a new release. [Release to New Release](../../release-to-new-release/index.md) walks through every step. For the filing page itself, see [Filing Manager overview](../../filing-manager/index.md).
