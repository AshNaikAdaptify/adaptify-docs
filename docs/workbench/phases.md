# Move work through phases

Each Workbench project follows a workflow made of phases. When your part is done, you submit the project to the next phase and hand it to the next person.

## Steps

1. Go to **Workbench** and open the project. If your update covers several types, open the child project you're working on, for example the forms project.
2. Check the current phase on the project page.
3. Select **Submit**.
4. Choose the assignee for the next phase. Select the circle next to the person's name. `TODO verify` the field labels in the Submit dialog.
5. Pick a due date from the calendar.
6. Add notes for the next person, for example "Ready for review."
7. Select **Submit**. The project moves to the next phase.

!!! tip
    Pick dates from the calendar instead of typing them. Wait for the dialog to finish before you move on.

## Phases by project type

| Project type | Workflow | Phases |
|---|---|---|
| Forms | **Product Update** | **Select** → **Review** → **Approve** → **End** |
| Rates | **Rate Update** | **Select** → **End** |
| Rules | **Rule Update** | `TODO verify` |

Your organization admin manages these workflows under **Workflow management** on the Dashboard. `TODO verify` whether your organization's workflows have the same phases.

## What happens next

When every child project reaches **End**, complete the project. See [Complete a project](complete-project/index.md).
