# Workbench overview

**Collaborative environment for building new products and updating existing products.**

The Project Workbench (the Workbench) is where your team makes changes together. Each project moves through clear phases, like **Select**, **Review**, **Approve** and **End**. At each handoff, you add notes for the next person. When the work is done, you complete the project: straight to a new release in the Product Vault, or through a filing for each state in Filing Manager.

Open it from **Workbench** in the left navigation.

## What you see

- **The page header:** "Collaborative workspace to plan, execute, and track product changes from idea through approval, filing, and implementation."
- **Cards for the kinds of work:**
  - **Form updates:** modify policy forms and endorsements.
  - **Rate updates:** adjust rating factors and structures.
  - **Rules updates:** modify underwriting rules.
  - **New product:** create a new insurance product.
- **Project portfolio:** your projects, with a count. Each row shows the project, its current phase under **Status**, its state under **Jurisdiction**, the **Product**, the due date and who it's assigned to.
  - Filter them with **Type**.
  - Switch between list and grid views.
  - Turn on **Show Archived Projects Only** to see archived projects.
- **+ New project:** at the top right of the **Project portfolio**. See [Create a project](create-project/index.md).

## Which project do I need?

| You want to | Start |
|---|---|
| Change forms, rates or rules of a published product | **Product update**. See [Start a product update](create-project/product-update.md). |
| Sell a product you already have in a new state | **New product** → **New jurisdiction for existing product**. See [Start a project to add a state](create-project/new-jurisdiction.md). |

## Inside a project

A project page shows a phase stepper, for example **Select**, **Review**, **Approve** and **End**, with the person working on each phase. Below it are tabs for the work, such as **Forms**, **Notes**, **Team** and **Activity**.

A combined project lists its child projects on a **Projects** tab and shows how many are complete.

Select **Show details** to see the project's description, its states, when it was created and when it's due.
