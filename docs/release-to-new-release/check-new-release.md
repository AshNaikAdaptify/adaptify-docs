# Check the new release in the Product Vault

Do this after you archive each state's filing. The Product Vault now shows the new release as that state's current release.

## Steps

1. Open **Product Vault** and choose your product, for example **Personal Auto**.
2. Under **Jurisdiction**, choose the state. **Release** shows the new release, for example **Release 1**, with the **Current release** chip and the **New business** and **Renewal** dates you entered.
3. On the **Forms** tab, updated forms show an **Update** chip, for example **Update AL**. Check that each one shows its new edition.
4. To see the earlier version, choose an earlier release, such as **Baseline**, under **Release**. See [Understand releases](../product-vault/releases.md).
5. Repeat for each state.
