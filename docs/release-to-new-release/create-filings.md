# Create filings from your project

Do this when every child project in your Workbench project is complete. Completing the project as **Admitted** creates a filing for each state in [Filing Manager](../filing-manager/index.md). For more about this dialog, see [Complete as Admitted](../workbench/complete-project/admitted.md).

## Steps

1. Open the combined project and choose **Complete project**.
2. Choose the **Admitted** tab.
3. Under **Destination states**, check that each state you're filing in is listed, for example **Alabama (AL)** and **Alaska (AK)**.
4. For each state, fill in **Approval Type** (for example **Prior approval** or **File and use**) and **Owner**.
5. Review the summary. It groups the changes by state and shows each **Asset**, its **Change** and its **Scope**. Then confirm.
6. Open **Filing Manager**. Each state now has its own filing, for example "Filing - Personal Auto – Fall 2026 forms and rates update (Form, Rate) (AL)".

## Fields (per state)

| Field | Example |
|---|---|
| **Approval Type** | Prior approval |
| **Owner** | Your filing owner |

Pick any dates from the calendar. Typed dates may not be saved.

If a state doesn't need a filing, use the **Non-admitted** tab instead. See [Complete a project](../workbench/complete-project/index.md).
