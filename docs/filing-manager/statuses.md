# Filing statuses and dispositions

A filing page shows a status for its package, its submission and each objection. This page lists the values confirmed so far. `TODO verify` the full list and what each value does.

## Filing package

| Status | Meaning |
|---|---|
| **Not generated** | No package yet. |
| **Generated** | The package was built and downloaded as a ZIP with **Generate filing package**. |

## Submission and disposition

You record the submission with **Manual submission**. The **Disposition status** then tracks the state's decision. To change it, select the status chip next to **Submission**, set **Disposition status** and the **Change date**, and save.

| Status | Meaning |
|---|---|
| **Not started** | The submission hasn't been recorded yet. |
| **Pending** | Submitted to the state and waiting on a decision. |
| **Approved** | The state approved the filing. You can now archive it with **Archive project** and create the new release. |

## Approval type

You set the approval type for each state when you complete a project as Admitted, and it shows again when you record the submission.

| Approval type | Meaning |
|---|---|
| **Prior approval** | The state must approve the filing before you use it. |
| **File and use** | You file with the state and can use the filing once it's filed. |
| **Use and file** | You can use the filing first, then file it within the state's deadline. |

## Objections

| Status | Meaning |
|---|---|
| **In Progress** | The objection is logged and your response is being prepared. |
| **Response submitted** | You built the response package for this objection. |
