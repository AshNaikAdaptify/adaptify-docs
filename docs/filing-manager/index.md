# Filing Manager overview

**Filing Manager** holds your filings being prepared for submission to regulators, from the first package to approval. Each filing covers one state. Filings are created when you complete a Workbench project as Admitted. See [Complete as Admitted](../workbench/complete-project/admitted.md).

## Find a filing

1. Select **Filing Manager** in the left navigation. The **Filings** count shows how many filings you have.
2. Use **Search**, **Filters**, **Sort** and **Group** to narrow the list.
3. Open a filing. You can also open one from **Active projects** on the Dashboard.

A filing's name comes from its project and state, for example "Filing - Personal Auto fall update (Form, Rate) (AL)".

## What's on a filing page

| Area | What it shows |
|---|---|
| **Path to submission** | A progress tracker for the filing. |
| **Filing package** | **Not generated** until you select **Generate filing package**, then **Generated**. |
| **Submission** | **Not started** until you record it with **Manual submission**, then the disposition, such as **Pending** or **Approved**. |
| **Objections** tab | The state's objections and your responses. Add one with **+ Add objection**. |

## Where each task starts

| Task | Start with |
|---|---|
| Download the filing package (ZIP) for the state | **Generate filing package** |
| Record the date and SERFF tracking number | **Manual submission** |
| Log an objection and build your response | **Objections** tab → **+ Add objection** |
| Record the state's decision | The **Submission** status chip |
| Close the filing and create the new release | **Archive project** |

!!! note "Each state moves on its own"
    Each filing is submitted, approved and archived separately. One state can reach its new release while another is still answering an objection.

The [Release to New Release](../release-to-new-release/index.md) guide covers each task step by step. For what each status means, see [Filing statuses and dispositions](statuses.md).
