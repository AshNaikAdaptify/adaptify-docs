# Support

## Get help with Adaptify

Use **Report a problem with this page** at the bottom of the page.

To get help faster, include the page you were on, what you were trying to do and what you saw.

## Report a problem with the docs

1. Go to the page with the problem.
2. At the bottom of the page, choose **Report a problem with this page**. It opens a pre-filled issue.
3. Describe what's wrong, where on the page, and what you expected.

## Tell us if a page helped

At the bottom of any page, answer **Was this page helpful?** with **Yes** or **No**. Each opens a short pre-filled issue where you can add details.
